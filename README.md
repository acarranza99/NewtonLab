
# NEWTON LAB
### Laboratorio interactivo para aprender las tres leyes de Newton

## Descripción
Newton Lab es una aplicación web educativa que permite aprender y experimentar con las tres leyes del movimiento de Isaac Newton mediante simulaciones interactivas.

El estudiante puede modificar parámetros físicos, observar el comportamiento de los objetos, analizar gráficos y registrar resultados.

## Objetivo general
Facilitar la comprensión de las leyes de Newton mediante experimentos virtuales que relacionan la teoría física con situaciones visuales e interactivas.

## Experimentos disponibles

### 1. Primera ley: Inercia
Permite modificar la masa, fuerza aplicada y fricción de un objeto para observar cómo cambia su movimiento.

### 2. Segunda ley: Fuerza y aceleración
Permite experimentar con masa y fuerza, observar la aceleración en tiempo real y analizar su relación mediante un gráfico.

### 3. Tercera ley: Acción y reacción
Simula la interacción entre dos astronautas para observar las fuerzas iguales y opuestas, así como sus diferentes respuestas según la masa.

## Funcionalidades
- Simulaciones animadas.
- Controles de masa, fuerza y fricción.
- Indicadores de velocidad y aceleración.
- Gráficos físicos en tiempo real.
- Cronómetros experimentales.
- Bitácoras de ensayos.
- Exportación de resultados a Excel.
- Interfaz visual diferenciada para cada ley.

## Instalación y ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta NewtonLab en Visual Studio Code.
3. Abrir index.html en un navegador moderno.
4. Seleccionar uno de los tres experimentos.
5. Modificar los parámetros y comenzar a experimentar.

También puede utilizarse Live Server para ejecutar el proyecto desde un servidor local.
